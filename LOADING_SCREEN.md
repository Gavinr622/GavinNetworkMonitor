# Custom Loading Screen

## Settings
Use Admin Settings to change: enabled, minimum duration (3+ seconds), title, subtitle, background, accent, and spinner interval. Changes apply on the next launch.

## Advanced customization
Edit `loading_screen.py`. `LOADING_LINES` uses `(status, detail, percentage)`.

## Files
- `config/settings.json`: saved loading settings
- `loading_screen.py`: default/custom splash values
- `docs/index.html`: bundled documentation
