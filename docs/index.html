Gavin Network Monitor 7.3

Built-in documentation for the network metadata monitor.

Privacy: the monitor is designed for traffic metadata visible to your own computer. It does not display packet payloads, passwords, or message contents.

Navigation / Side Menu

The main app has a left-side navigation menu for Live Traffic, Domain Matches, Packet Headers, and Command Console. It also provides quick buttons for Documentation and Settings. The main app header stays separate above the navigation and content.

Getting Started

  1. Choose a capture interface.
  2. Press START.
  3. Use filters to inspect protocol, address, and port metadata.

Admin Command Center

Use Admin → Admin Command Center after signing in. Custom commands and app shortcuts are stored in config/.

Settings

Settings are saved in config/settings.json.

General

Fullscreen, automatic saving, DNS refresh, default filters, and selected interface.

Loading Screen

Startup splash, minimum duration, title, subtitle, colors, spinner interval, and the optional custom Python loader.

Loading Screen

The startup splash is shown before the main GUI. The main window stays hidden until startup is complete. The configured minimum duration is enforced at 3 seconds or longer.

Show loading screen — enable or disable the startup splash.
Minimum seconds — minimum time the splash stays visible. Values below 3 are automatically raised to 3.
Title / Subtitle — text displayed on the splash.
Background / Accent — Tkinter color values such as #171a21 and #66c0f4.
Spinner interval — animation update speed in milliseconds. Lower values animate faster.

Custom Python Loading Screen

You can make your own Python startup theme without editing app.py. The included template is config/custom_loading_screen.py.

Step 1 — Enable it

Open Admin → Admin Settings or the sidebar ⚙ Settings, enable Enable custom Python loading screen plugin, save, and restart.

Step 2 — Edit the Python file

Change these values:

TITLE = "MY NETWORK TOOL"
SUBTITLE = "STARTING..."
BG = "#090d12"
ACCENT = "#66c0f4"
SPINNER_INTERVAL_MS = 80

Loading line format

Each entry must be:

(status text, detail text, percentage)

Example:

LOADING_LINES = [
    ("Loading Npcap", "Checking interfaces", 70),
    ("Ready", "Launching monitor", 100),
]

The custom file controls the splash title, subtitle, colors, spinner speed, and startup stream. If the custom loader contains an error, the application falls back to its built-in loader.

Documentation Button

Use Help → Documentation or the sidebar 📚 Documentation to view this bundled documentation inside the application. Open HTML opens the original file in your browser.

Folders

  • cmd/ — admin command system
  • config/ — persistent settings, custom commands, apps, and the optional custom Python loader
  • docs/ — bundled documentation
  • loading_screen.py — built-in loading-screen defaults

Customization

Keep backups before editing configuration or Python files. Loading-screen settings are persisted in config/settings.json. The custom loader is optional and can be disabled from Admin Settings.
